# Working with this research release

Open an issue with a reproducible input description, platform, package versions,
expected behavior and relevant error. Do not attach restricted imagery, private
locations, credentials or sensitive uploads to public issues. For a scientific
change, identify the protocol, candidate/control hashes, valid support, units,
geographic exposure and decision rule. Preserve unfavourable measurements.

Development commands are in `docs/SETUP.md`. Keep exported raw products independent
of display styling. Update the relevant technical chapter and tests when units,
coordinate behavior, interfaces or model selection change. A model or data
licence must permit the proposed contribution and redistribution. Original code
reuse permissions are described in `THIRD_PARTY_NOTICES.md`.
