# Research source inventory

The documentation is grounded in implementation, tests, run protocols, outcome
records and explicit decision notes. The following dated records preserve what
was attempted, what was measured, what was rejected and what became app behavior.
They are grouped in the handbook after the current technical chapters.

Historical records have public names and paths normalised. A local artifact path
mentioned inside a record is an archive locator, not a promise that a large
training output is committed. Exact public bytes are indexed in
`docs/evidence/source-inventory.json`. New current chapters resolve conflicts in
favor of the state documented on 28 September 2026 while retaining older outcomes.
