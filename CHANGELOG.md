# Changelog

## 0.1.0 — 28 September 2026

- Scientific source release with dated technical handbook, decision ledger,
  experiment outcomes, data provenance and explicit limitations.
- Portable inference bundles preserving learned tensors, SHA-256 download
  manifest, model notices and original upstream licensing.
- Urban, sparse, forest and georeferenced terrain viewing, image import,
  six-category classification, inspection, navigation and scientific exports.
- Separated raw scientific products from presentation effects and coarse terrain
  demonstrations from broader measured-building/canopy development evidence.
- Public identity normalisation, restricted imagery exclusion and dependency
  security updates. Active research work continues beyond this snapshot.
